# 本地视频拼接器

把讲道视频和人物反应视频合成一条竖屏视频。视频留在自己电脑里，不会上传。

## 打开

用 Chrome 或 Edge。打开 `app` 文件夹里的「本地视频拼接器-v2.0.html」，就能用。

## 使用

1. 在右边把讲道视频拖进「讲道／成品视频」。可以一次拖好几个。左边会出现对应的单元，右上角显示一共有几个。
2. 把人物反应视频拖进「人物反应视频」。拖进去时，框会变成浅蓝色。
3. 讲道视频有声音，长短以它为准。反应视频没有声音，短了会循环，长了会截掉。
4. 右边可以调画面：上下分屏、左右分屏、画中画，也可以加标题和横幅。右边改一次，左边所有单元一起跟着变。
5. 某一个单元要单独改，就改那个单元自己的设置。改过的那一项会保持住。想改回去，点该单元右上角的「撤销单元设置」。视频还在，只是设置回到右边的统一设置。
6. 只给一条视频加标题、不需要反应视频时，勾选「仅给单个视频添加标题」。
7. 点「开始批量导出」。左边每个有讲道视频的单元，各导出一条视频，做完一条再做下一条。文件由浏览器下载到电脑。

导出时可以在「导出质量」里选清晰度。文件名可以在「导出命名」里改。
